# ステップ1：「上手な断り方」を言葉にする（15分）

## ねらい

AI の出力を評価するには、まず **何をもって「良い」とするか** を決める必要があります。
「上手な断り方」は誰でもなんとなく分かっていますが、いざ説明しようとすると難しいものです。
頭の中にある「なんとなくの良さ」を、誰が見ても同じ判断ができる言葉に変えるのがこのステップです。

## やること

1. [`prompt-v1.md`](prompt-v1.md) を読む。これが最初の指示です（2分）
2. 新しいチャットを開き、下のプロンプトを貼り付けて Claude と対話する（10分）
3. できあがった「合格基準」をメモに残す（3分）。ステップ3の採点表と見比べます

## Claude に渡すプロンプト

```
AI に「断りの返信」（飲み会の誘いや頼まれごとを断る LINE やメール）を書かせようとしています。
その前に、「上手な断りの返信」の合格基準を決めたいです。

進め方：
- 私に1問ずつ質問して、「上手な断り方」「下手な断り方」の条件を引き出してください。質問は5問程度までにしてください。
- 私の答えがあいまいなとき（例：「感じがいいこと」）は、誰が判定しても同じ結果になるように具体化するよう、問い返してください。
- 最後に、合格基準を次の2種類に分けて一覧にしてください。
  A. 見ればはっきり判定できる項目（はい／いいえで答えられるもの）
  B. 程度を評価する項目（1〜5段階で採点するもの）。各項目について「1点」「3点」「5点」がどんな状態かも書いてください。
```

## ふりかえりの問い

- 「感じがいい」「失礼じゃない」のような言葉は、そのままだと人によって判断がぶれます。どう言い換えましたか？
- A（はい／いいえ）と B（1〜5段階）、どちらに入れるか迷った項目はありましたか？
  迷ったら A に寄せられないか考えてみましょう。A のほうが採点がぶれにくく、速く測れます。
