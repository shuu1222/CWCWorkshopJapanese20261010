# ステップ3：ベースラインを測る（15分）

## ねらい

指示を直し始める前に、**いまの指示（v1）が何点なのか** を測って記録します。これが「ベースライン」です。
ベースラインがないと、あとで指示を直したときに「良くなったのか、変わっていないのか、悪くなったのか」が分かりません。

採点は2段階で進めます。

1. **返信を作る** — v1 の指示で、10件すべての場面に返信を書かせる
2. **採点する** — **別の新しいチャット** で、Claude に採点係をやってもらう

> 採点を別のチャットで行うのは、返信を書いた本人に採点させると甘くなりがちだからです。
> 人間でも、書いた人と確認する人は分けたほうがミスに気づけますよね。

## やること

1. [`rubric.md`](rubric.md) を読む（2分）
2. 下の「プロンプト①」で返信を作る（3分）
3. 新しいチャットを開き、「プロンプト②」で採点する（4分）
4. 採点結果を [`scoresheet.csv`](scoresheet.csv) に貼り付け、C4（長さ）は文字数カウントツールで自分で測って埋める（3分）
5. **自分による答え合わせ**：2件だけ選んで、Claude の採点を見る前に自分で採点し、比べる（3分）
6. 合格数とスコア平均を計算し、「v1：合格 ◯/10、平均 ◯.◯」とメモする

## プロンプト①：返信を作る

`{{ … }}` を置き換えてから、新しいチャットに貼り付けてください。

```
以下の「指示」に従って、10件の場面それぞれへの返信を書いてください。

- 10件はそれぞれ無関係な場面です。ほかの場面の内容を参考にしないでください。
- 出力は、場面ごとに「### R01」のような見出しをつけ、その下に返信の文面だけを書いてください。説明や補足は不要です。

# 指示
次のメッセージに、断りの返信を書いてください。

# 場面
{{ testcases.csv の case_id・相手・届いたメッセージ・私の事情 の4列 }}
```

> 「上手な断り方のポイント」の列は、ここでは渡さないでください。答えを見せてから問題を解かせることになってしまいます。

## プロンプト②：採点する

**新しいチャットで** 実行してください。

```
あなたは、断りの返信を採点する、厳格で公平な採点係です。
以下の「採点表」にしたがって、各場面の返信を採点してください。

# 採点表
{{ rubric.md の中身 }}

# 場面（届いたメッセージ・私の事情・上手な断り方のポイント）
{{ testcases.csv の中身 }}

# 採点する返信（バージョン：v1）
{{ プロンプト①の出力 }}

採点のしかた：
- 場面ごとに、まず採点表の各項目について短く根拠を検討してから点をつけてください。
- 「上手な断り方のポイント」と食い違う内容があれば、厳しく減点してください。
- C4（長さ）は採点せず、空欄にしてください。人間が文字数を測って埋めます。
- 迷ったときは甘くせず、低いほうの点をつけてください。

最後に、すべての場面の結果を次の形式の CSV にまとめ、コードブロックで出力してください。
case_id,version,C1,C2,C3,C4,C5,S1,S2,合否,理由
- C1〜C5 は「✅」か「❌」（C4 は空欄）
- S1・S2 は 1〜5 の数字
- 合否は「合格」か「不合格」（C4 を除いて判定）
- 理由は不合格の主な原因を30字以内で。半角カンマと改行は使わないでください
```

## ふりかえりの問い

- v1 はどの場面で落ちましたか？ 落ち方に共通点はありましたか？（ありがちなのは「長すぎる」「理由を作ってしまう」「また誘ってねと書いてしまう」です）
- 自分の採点と Claude の採点は一致しましたか？
  大きくずれた項目があれば、それは **採点表の書き方があいまい** なサインです。ステップ4で採点表のほうを直すこともあります。
