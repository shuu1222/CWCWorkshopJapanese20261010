# 採点表

1件の返信を、**チェック項目5つ（✅ / ❌）** と **スコア項目2つ（1〜5点）** で採点します。

## チェック項目（✅ / ❌）

はい／いいえで判定できる項目です。1つでも ❌ があれば不合格です。

| ID | 項目 | ✅ の条件 |
|---|---|---|
| C1 | はっきり断っている | 読んだ相手が「OK なのか NG なのか」迷わない。一部だけ断る場面では、何を断り何を受けるのかが明確 |
| C2 | 作り話をしていない | 「私の事情」に書かれていない理由（「先約がある」「お金がない」など）を作っていない |
| C3 | 期待を持たせすぎていない | 本当に次がない場面で「また誘ってね」「機会があれば」などと書いていない。代わりの案は「私の事情」にあるものだけ |
| C4 | 短い | 本文120字以内（英語なら60 words 以内）。宛名・署名は除いて数える |
| C5 | 相手に合った言葉づかい | 上司・取引先・保護者などには敬語、友人にはくだけた口調。英語のメッセージには英語で返している |

> **C4 は自分かツールで測りましょう。** AI は文字数を数えるのが苦手で、採点が不正確になりがちです。
> 文字数カウントツールに貼れば一瞬で正確に分かります。「機械で測れるものは機械で測る」のが評価のコツです。

## スコア項目（1〜5点）

程度を評価する項目です。3点未満が1つでもあれば不合格です。

### S1 相手への気づかい

| 点 | 状態 |
|---|---|
| 1 | 冷たい、そっけない、または相手を責める・否定するような印象を与える |
| 3 | お礼やおわびの言葉はあるが、決まり文句で、この相手・この場面に合わせていない |
| 5 | この相手との関係や場面に合った気づかいがあり、それでいて謝りすぎていない |

### S2 そのまま送れる自然さ

| 点 | 状態 |
|---|---|
| 1 | 不自然で、大きく書き直さないと送れない（硬すぎる、長すぎる、AI っぽい言い回しが多い） |
| 3 | 少し手直しすれば送れる |
| 5 | 自分が書いたように自然で、そのまま送れる |

### 点数ごとの例

場面：上司から LINE で「金曜の夜、部署の飲み会やるけど来られる？」／私の事情：保育園のお迎えがある

| 項目 | 点 | 例文 | 理由 |
|---|---|---|---|
| S1 | 1 | 「行けません。」 | お礼も事情もなく、冷たい印象 |
| S1 | 3 | 「お誘いありがとうございます。申し訳ありませんが、今回は欠席させてください。」 | 決まり文句で、この相手・この場面に合わせていない |
| S1 | 5 | 「お誘いありがとうございます！平日の夜は保育園のお迎えがあって、今回は欠席させてください。皆さんによろしくお伝えください。」 | 事情が伝わり、職場の人たちへの気づかいもある。謝りすぎていない |
| S2 | 1 | 「このたびは懇親会へのお誘いを賜り、誠にありがとうございます。誠に恐縮ではございますが、家庭の事情により参加いたしかねます。」 | LINE なのに硬すぎる。大きく書き直さないと送れない |
| S2 | 3 | 「お誘いありがとうございます。保育園のお迎えがあるため、参加することができません。申し訳ございません。」 | 内容は良いが少し硬い。少し手直しすれば送れる |
| S2 | 5 | （S1 の5点と同じ） | 自分が書いたように自然で、そのまま送れる |

## 合否と集計

- **合格** ＝ チェック項目がすべて ✅、かつスコア項目がすべて3点以上
- 指示のバージョンごとに、次の2つの数字を記録します
  - **合格数**（例：10件中4件合格 → 4/10）
  - **スコア平均**（S1・S2 の全件平均）
