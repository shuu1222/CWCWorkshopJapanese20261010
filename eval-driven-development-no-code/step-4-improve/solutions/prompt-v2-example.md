# 指示 v2 の改善例

> **ステップ4で自分の v2 を作るまでは見ないでください。**
> これは「正解」ではなく一例です。実際にどれだけ点数が上がるかは、測ってみないと分かりません。

---

次のメッセージに、断りの返信を書いてください。

- 最初の1〜2文で、断ることをはっきり伝える。
- 理由は「私の事情」に書かれていることだけを使う。事情が書かれていなければ、理由は書かずに断る。作り話はしない。
- 「また誘ってね」「機会があれば」など、次を期待させる言葉は、私の事情に次の可能性があるときだけ書く。
- 代わりの案は、私の事情に書かれている範囲でだけ出す。
- 本文は120字以内にする。
- 相手との関係に合わせて、敬語かくだけた口調かを選ぶ。相手が英語なら英語で書く。

- 相手：{{ 相手 }}
- 届いたメッセージ：{{ 届いたメッセージ }}
- 私の事情：{{ 私の事情 }}

---

## この改善例について

ワークショップでありがちな失敗と、上の書き足しの対応関係です。

| よくある失敗 | 関係する場面 | 対応する書き足し |
|---|---|---|
| 「先約がありまして」など理由を作ってしまう | R02, R08, R10 | 「理由は私の事情に書かれていることだけ」 |
| 「また誘ってください」と書いてしまう | R03, R06, R08 | 「次を期待させる言葉は、次の可能性があるときだけ」 |
| 前置きが長く、断っているのか分かりにくい | 全般 | 「最初の1〜2文で断ることをはっきり」 |
| 長すぎる | 全般 | 「120字以内」 |

ただし、書き足しすぎると別の問題が起きることもあります。たとえば「120字以内」を強く言いすぎると、
R06（告白を断る）のように気づかいが大事な場面でそっけなくなり、S1（相手への気づかい）が下がるかもしれません。
**だからこそ、全ケースで測り直すのです。**
